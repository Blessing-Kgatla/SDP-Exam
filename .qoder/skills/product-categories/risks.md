# Category-specific risks and special considerations

| Product | Special risks/review priorities |
|---|---|
| E-commerce | Inventory accuracy, tax, shipping, refunds, fraud, payment reconciliation |
| Marketplace | Seller verification, dispute resolution, commissions, moderation, buyer protection |
| Restaurant | Accurate menus/allergens, pickup times, reservations, ordering and fulfillment |
| Travel | Date/time zones, supplier availability, booking changes, cancellations |
| Hotels | Room/occupancy rules, double booking, fees, cancellation/refund transparency |
| Real estate | Property accuracy, agent identity, location accuracy, listing freshness |
| Events | Ticket inventory, duplicated admission, cancellations, refund workflows |
| Service booking | Staff availability, time zones, rescheduling, no-show policies |
| Corporate | Authentic claims/case studies, contact conversion, accessibility, brand trust |
| SaaS | Tenant isolation, roles, account recovery, billing, quotas, support |
| ERP | Data accuracy, bulk edits, permissions, audit history, business continuity |
| Project management | Concurrent edits, notifications, ownership, deadline/timezone behavior |
| CRM | Private contact information, deduplication, consent, exports |
| Banking/fintech | Ledger invariants, reconciliations, fraud, regulated integrations, audits |
| Recruitment | Applicant privacy, fair workflows, consent, applications retention |
| Developer tools | API stability, keys/quotas, docs, observability, backwards compatibility |
| News | Editorial integrity, timestamps, sources, copyright, corrections |
| Streaming | Media rights, delivery, playback quality, subtitles, billing |
| Gaming | Input latency, fairness, progression, performance, saves and online abuse |
| Portfolio | Asset licensing, truthful project claims, accessibility, load speed |
| LMS | Assessment integrity, student records, grading correctness, role scopes |
| University | Accessibility, academic calendar changes, admissions clarity, institutional accuracy |
| Documentation | Versioning, broken links, search, clear examples, provenance |
| Social media | Abuse, moderation, privacy, media storage, spam/bots, data protection |
| Messaging | Delivery semantics, safety, privacy/encryption decisions, offline behavior |
| Forums | Moderation, spam, nested discussion UX, archiving/search |
| Dating | Consent, age/safety controls, location privacy, reporting and blocking |
| Healthcare | Sensitive records, consent, clinical safety, formal validation |
| Fitness/running | GPS reliability, screen-off recording, sensor precision, battery and data loss |
| Productivity | Durable local records, quick input, reminders, cross-device decisions |
| Budgeting | Monetary precision, backups, exports, financial privacy |
| Government/civic | Accessibility, service rights, auditability, public-sector reliability |
| Nonprofit | Donation security, verifiable impact, transparency, consent |
| Logistics | Geo accuracy, dispatch, intermittent connectivity, driver safety |
| Maps/navigation | Licensing, routes/geocoding, changing roads, location privacy |
| Creative editor | Data loss, undo/redo, precision, performance, non-destructive edits, export |
| Cybersecurity | Event ingestion integrity, alert fatigue, safe access and response |
| AI applications | Output quality evaluation, hallucinations, prompt injection, model/privacy costs |
| Automotive | Vehicle identity, maintenance accuracy, physical/safety-sensitive recommendations |
| Desktop utility | Platform permissions, privilege boundaries, installer/update safety, local privacy |

For **AI features**, document model choice, inference location, evaluation dataset, latency, hallucination/error behavior, source attribution where relevant, data sharing, cost, fallback, and human review for consequential decisions.

# Brand colour-palette suites for the 40 product categories

Every six-color suite supplies these **design tokens**:

- **Primary:** Brand identity, priority actions, selection emphasis.
- **Secondary:** Supporting elements, secondary data series, quieter highlights.
- **Accent:** Rare important highlights, not every button/icon.
- **Background:** Main page canvas.
- **Surface:** Cards, modals, panels, elevated regions (when appropriate).
- **Text:** Default foreground text/headings, with separate muted variants as needed.

**Do not simply apply palettes wholesale.** Adapt to actual brand, audience, market position, cultural context, media, accessibility, and product needs. Colors below are starting points; test foreground/background/button-state contrast rather than assuming every pairing passes accessibility requirements.

### Color implementation and accessibility

A useful **illustrative** visual balance is ~70% neutral backgrounds/surfaces, ~20% brand identity, ~10% accent. This is not a rigid distribution; typography/foreground colors are applied wherever required.

```css
/* Example only: editorial e-commerce. Replace per project. */
:root {
  --color-primary: #233B31;
  --color-secondary: #A17A57;
  --color-accent: #BB513C;
  --color-background: #F8F4EC;
  --color-surface: #FFFFFF;
  --color-text: #222822;
  --font-heading: Georgia, serif;
  --font-body: Arial, sans-serif;
  --radius-small: 4px;
  --radius-medium: 8px;
  --content-width: 1280px;
  --page-gutter: clamp(16px, 4vw, 64px);
}
```

Maintain distinct semantic tokens for `success`, `warning`, `error`, `info`, `disabled`, `focus`, and appropriate text/on-color foregrounds. Validate WCAG 2.2 contrast: commonly ≥4.5:1 for normal text, ≥3:1 for large text and relevant nontext UI, plus other applicable success criteria. Don't assume an accent color is readable with white text.

**Rules this audit implies:**

1. **Text on background/surface** passes everywhere; use it for body copy.
2. **Primary** works as link/text colour and as a button fill with the listed label colour in 38 of 40 palettes. **#19 Gaming** and **#39 Automotive** fail. Use the adjusted primaries below or verify your own.
3. **Accent** is below 3:1 against the light backgrounds in most palettes. That makes it a **fill colour** (badges, highlights, chart areas) with the listed dark label, never a thin icon, border, focus ring or text colour on the page background.
4. **Secondary** is below 4.5:1 almost everywhere. Use it for large text, decoration, dividers and data series, not for body or helper text. Add a separate `--color-text-muted` token that is darker than secondary and verified at ≥4.5:1.
5. **Focus indicators** need ≥3:1 against adjacent colours. Derive a `--color-focus` token (often the primary, or the text colour on dark themes) and test it. Don't reuse the accent by default.
6. Recheck the ratios after any palette adaptation, every dark-mode variant and every state colour (hover, pressed, disabled, success/warning/error).
